AI智营宝 V3.2.1 修改：

1. 保留原 app.js 全部代码。

2. 在 Top-5显示位置：

原：
${translateFoodLabel(item.name)}

${translateTop5(item.name)}

或者：

${translateFoodLabel(item.name.toLowerCase())}


3. 如果使用独立翻译模块，需要在 index.html 中：

原：
<script src="./app.js"></script>

<script src="./top5_translate.js"></script>
<script src="./app.js"></script>


原因：
原代码已经有翻译函数，但Top-5显示没有调用正确的中文转换函数。
