AI智营宝图像识别大模型接入说明

一、普通网页版
1. 不要把大模型 API Key 写入 app.js 或 index.html。
2. 在 outputs 目录启动代理服务：
   PowerShell:
   $env:DASHSCOPE_API_KEY="你的API Key"
   node vision-proxy-server.js
3. 浏览器打开：
   http://localhost:8787
4. 默认模型：
   qwen-vl-plus
5. 可选环境变量：
   AIYINGBAO_VISION_MODEL：修改模型名称。
   AIYINGBAO_VISION_API_URL：修改 OpenAI 兼容接口地址。
   AIYINGBAO_VISION_API_KEY：备用 API Key 变量。

二、微信小程序版
1. 在微信开发者工具中打开 outputs/wechat-miniprogram。
2. 开通云开发，并部署云函数：
   cloudfunctions/recognizeFoodImage
3. 在云函数环境变量中配置：
   DASHSCOPE_API_KEY=你的API Key
4. 小程序前端调用云函数 recognizeFoodImage，前端不保存 API Key。
5. 如果未启用云开发、云函数失败或模型返回异常，小程序会自动使用本地规则兜底。

三、识别结果
大模型返回结果建议为：
{
  "foodKey": "beefRice",
  "label": "牛肉盖饭",
  "dishName": "牛排温泉蛋盖饭",
  "confidence": 0.91
}

目前支持的分类包括：
轻食碗、面食、沙拉、米饭套餐、牛肉盖饭、牛肉面、粥品、包点、鱼虾、火锅、汉堡、水果、百合绿豆水、杯装咖啡。
